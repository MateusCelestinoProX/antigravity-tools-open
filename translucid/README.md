# 💎 Translucid Antigravity Tools

Estética **Simple Glass + Multi-Light Effects** (Plasma Lava Orbs, Deep Horizon Radiant, Celestial Radiance, etc.) para o **Antigravity Tools** (Desktop & Web).

## 🚀 Como Aplicar em 1 Clique

```bash
chmod +x apply-translucid.sh
./apply-translucid.sh
```

## ✨ Funcionalidades
- 🔮 **Simple Glass Interface**: Vidro translúcido com desfoque profundo (`backdrop-filter: blur(25px)`).
- 🌋 **6 Efeitos de Energia em Tempo Real**: Plasma Lava Orbs, Deep Horizon Radiant, Celestial Radiance, Cyber Pulse, Aurora Waves e Pure Glass.
- 🎨 **37 Temas Profissionais + Cores Customizadas** (<kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>T</kbd>).
- 📊 **Botão Dashboard**: Acesso direto ao Control Center em `http://localhost:3030/`.
- 🌐 **Acesso Web ao Vivo**: `http://127.0.0.1:8045/`.
